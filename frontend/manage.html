작업일보 사진 → Claude 가 읽기

jpg/png/pdf 한 장. Claude 가 항목을 읽어 미리보기로 보여줍니다. 확인 후 저장합니다. 중단하면 백엔드 요청도 취소하지만, Anthropic에 이미 전달된 요청은 사용량이 청구될 수 있습니다. (팀 OCR 검토 흐름과 같은 의미: 추출 → 사람 검토 → 업무 테이블)
대기 중 · 이미지를 선택하고 OCR 시작을 누르세요. 상단 로그인 상태와 OCR 상태는 별도로 표시됩니다.

사슬이 끊긴 CA 제품 LOT

"이 자리 입력"을 누르면 직접 입력 폼에 모델·공정·날짜가 채워집니다. 상위 작업일보를 찾아 투입 LOT 까지 적어 주세요.

연결 확인 (CANDIDATE → CONFIRMED)

LOT 코드를 넣으면 그 LOT 의 투입 자재와 최종검사 연결이 나옵니다. 원본을 보고 맞으면 확인을 누르세요. 공정 간 INPUT 연결은 LOT 추적 화면의 edge id 로 확인합니다.
