CA 초품 핀 위치도 입력

A1-3 초품 위치도 엑셀에서 블록(제목 줄부터 NO 6까지)을 그대로 복사해 붙여넣으세요. 여러 날 블록을 한 번에 붙여도 제목 줄마다 하루로 나눠 저장합니다. 제목의 모델·날짜는 자동으로 채우고, 측정 안 한 빈 양식 줄은 건너뜁니다. 5칸(NO 좌X 좌Y 우X 우Y)만 붙여도 됩니다. 판정 기준(기준 X·Y, SPEC ⌀, 관리기준 ⌀)은 DB 에 등록된 값으로 미리보기에서 바로 계산합니다. 저장하면 팀 표 quality_check(초품) + measurement 에 들어가고, 그날·그 모델 CA 실행이 1건이면 자동 연결됩니다. 같은 모델·날짜를 다시 저장하려면 "기존 기록 바꾸기"를 켜세요(이전 기록은 지우지 않고 VOID). 모든 저장은 CRUD 이력에 [압입(CA)] 로 남습니다.

사출조건 체크시트 (IV·OV·HSV 같은 양식)

사출조건 체크시트 엑셀을 올리면 탭 이름 = 보빈(사출) LOT 으로 탭마다 읽습니다. 사진 탭은 건너뛰고 셀 값만 읽으므로 사진이 든 무거운 파일도 괜찮습니다(30MB 이하).
저장하면 팀 표에 들어갑니다: parameter_observation(주·야 실측) → 같은 모델 process_run(그 LOT 을 만든 사출 실행, FK) · 설비 DS120-1 · 시트·셀 출처(source_location·field_provenance_link). 잘못 넣은 탭은 아래 목록에서 삭제(VOID) — CRUD 이력에 [사출] 로 남습니다.
대기 중 · 체크시트 엑셀과 모델을 고르세요

입력된 사출조건 탭

사출 보빈 초품 위치도 (월별 엑셀 · 캐비티 1~16 × 좌·우)

엑셀 블록을 복사해 붙여넣거나 월별 파일을 올립니다. 값 없는 양식 블록은 건너뛰고, 값이 똑같은 블록은 복사본으로 표시해 기본으로 빼 둡니다.
1블록 = 초품 1회 = BB LOT(제목 날짜 + ㈜→D1 / (야)→N1). 저장하면 quality_check(보빈 초품) → 그 BB LOT 을 만든 process_run(사출, FK) · measurement(캐비티·좌우 X/Y). 판정은 DB 기준(X 2.1 · Y 12.0 · SPEC ⌀0.35 · 관리기준 ⌀0.40)이 계산합니다. 잘못 넣은 것은 아래 목록에서 삭제(VOID) — CRUD 이력 [사출].

① 엑셀에서 블록 복사 → 붙여넣기 (CA 위치도와 같은 방식)

블록을 제목 줄(iMEB3 IV BOBBIN … 26.08.27(야))부터 복사하면 모델·날짜·주야를 제목에서 읽습니다. 옆으로 붙은 블록 2개, 여러 블록을 한꺼번에 복사해도 됩니다. 숫자 줄(NO 1~16)만 복사했으면 아래 모델·측정일·주야를 고르세요. 제목에 주/야가 없을 때도 아래 주야가 쓰입니다.
② 또는 월별 엑셀 파일을 통째로 올리기

입력된 보빈 위치도

판독 기록 — 문서 종류별 Claude 호출 비교

작업일보(사출·BS·조립·최종검사)·재검사 비고를 Claude 로 읽을 때마다, 그리고 사출조건 체크시트·보빈 위치도 엑셀을 읽을 때마다 문서 종류 · 모델 · 입력/출력 토큰 · 판독 시간 · 읽은 항목 수 · 성공 여부를 DB(extraction_run)에 자동으로 남깁니다. 결과보고서 비교표는 아래 표를 복사해 쓰면 됩니다. 엑셀 판독은 Claude 를 부르지 않아 토큰이 0 입니다.

CRUD 이력 (공정 단계별)

모든 생성·수정·삭제(VOID)는 팀 감사 테이블 mqi_audit.row_change 에 자동으로 남습니다. 여기서는 그 기록을 저장 1회(트랜잭션) 단위로 묶고, 바뀐 행이 어느 공정에 속하는지 풀어서 보여 줍니다. 누가 = actor(로그인 사용자 가림) · 무엇을 = [공정] 입력경로 · 요약. 행을 누르면 바뀐 표·열이 나옵니다.
