## 1. 과제 개요 — 미션과 필수 요건

### 1-1. 미션 핵심 요약

5개월 동안 배운 것을 **실제로 배포하고 사용자 피드백까지 받는 AI 서비스**로 증명하는 캡스톤 프로젝트.
평가는 결과물뿐 아니라 **"문제 정의 → 설계 → AI 구축 → 프론트 연동 → 배포 → 피드백 반영"** 전 과정을 설명할 수 있는지를 본다.

### 1-2. 우리 프로젝트에 대입

| 미션 요구 | 우리 프로젝트 |
|---|---|
| 실제 사용자의 문제 | 공장 수기 작업일보·최종검사 일보가 종이로만 남아 **LOT 추적과 불량 원인 분석이 어려움** |
| 타겟 사용자 | 품질·생산 담당자 (불량 발생 시 이력 추적이 필요한 사람) |
| AI 핵심 기능 | 수기 일보 스캔(PDF·사진)을 **Claude API로 판독**해 숫자를 추출하고 DB에 적재 |
| 서비스 가치 | 원소재 → 공정 → 제품 → 검사 → 출하까지 **정방향·역방향 추적**, 제품별 그래프 |
| 확장 목표 | 고객 불량·공정 불량 발생 시 설비 수리·사출조건 변동·검사 불량 유형과 연결해 원인 분석 |

### 3-2. M3-1 단계 — OCR 판독과 정답률

2. **숫자 오독 (43%)** — 손글씨 8↔6, 7↔1, 3↔2 혼동. 5자리 생산수량의 한 자리가 바뀌면 칸 전체가 오답(예: 스티칭 생산수량 …8… → …6…).
3. **행 밀림 (4%)** — 불량 표에서 값이 한 칸 위·아래 항목으로 들어감(예: 비전1차 수량이 용접불량 칸에, 내경불량 수량이 저항불량 칸에). 한 번의 밀림이 누락 + 헛판독 두 개의 오답을 만든다.

**스키마 동일성 원칙** (`AGENTS.md`)
- 테이블·컬럼 이름, 자료형, 제약조건, 허용값, 트리거를 바꾸지 않는다. 팀 기준 SQL 은 고치지 않고 그대로 적용한다.
- 개인 프로젝트에만 필요한 것(뷰·권한)은 별도 마이그레이션 파일에 "개인 프로젝트 전용"으로 둔다.
- 새 테이블·컬럼이 필요하면 만들지 않고 팀 DB 담당(이*규)에게 제안할 내용으로 기록한다(예: 측정 유형 '초품' FIRST_ARTICLE).

## 4. 어려움과 해결

| # | 문제 | 원인 | 해결 | 결과 수치 |
|---|---|---|---|---|
| 1 | 팀 DB 에 적재할 수 없음 | 팀 DB 쓰기 권한 없음 | 개인 `IMEB3 DB` 에 팀 마이그레이션을 수정 없이 적용, 스키마 동일성 원칙 | 테이블 50+1·FK 152·CHECK 229 동일. 전환은 이*규 승인 대기 |
| 2 | LOT 사슬이 거의 끊김 | 탐색 범위 7일, 같은 날 해석 오류, 자재 위치 혼동 | 15일 범위, 보빈 날짜 동일 모두 매칭, 자재 홈 공정 규칙 | 완전 사슬 8 → 25 / 57 |
| 3 | 8월 사출 LOT 이 추적에 없음 | 통합 CSV 에 8월 사출 일보가 8건뿐 | 원천 xls(18장) 찾아 23건 적재 | 25 → 41 / 57 |
| 4 | OV/HSV 가 합산돼 모델 구분 불가 | 판독본에서 합산 일보 보류 | 8월 조립 xls 로 모델별 분리 | CA LOT 57 → 74, 완전 사슬 49/74 |
| 5 | 다시 적재하면 기존 행과 충돌 | 삭제 금지 규칙 | 차이분(delta) SQL 만 적용, 사라진 행은 VOID | 7차까지 적용, 이력 보존 |
| 6 | 정답률이 낮게 나옴 | 정답지도 틀릴 수 있음 | 틀린 칸 219개를 원본 PDF 92쪽과 대조 | 59.7% → 62.3%, 정답지 오류 8건 |
| 7 | 사진 OCR 400 오류 | 구조화 출력 스키마가 너무 큼 | JSON 텍스트 + 항목별 검증 | Render 판독 성공 (약 18초) |
| 8 | 대시보드가 M1-2 와 다르게 바뀜 | 새 탭 화면을 따로 만듦 | M1-2 화면 복사 + 데이터만 mqi 뷰 | 피시본 그래프·모델 색 유지 |
| 9 | 그래프에 검사 연결이 안 보임 | 화면이 원문 재해석으로 mqi 연결을 덮어씀 | 재해석 제거, DB 연결 사용 | CA 쪽 검사 LOT 33 → 453 |
| 10 | 검사 수량 미확인 칸 | 검사 기록에 LOT 별 수량 없음 | 정답지 'Lot No'(LOT:BOX)로 97건 반영 | 미확인 34 → 7곳 |
| 11 | 검사가 엉뚱한 LOT 에 붙음 | "가까운 날짜" 추정 연결 | 원본 확인 → 추정 금지, 미연결 처리 | 미검증 10건 중 1건만 맞음 → 4 정정·6 미연결, 77건 → 69 재연결 |
| 12 | 날짜마다 화면 숫자를 따로 고침 | 프론트 고정 보정값 | 보정 삭제, 사실은 DB 에서 정정 | 검사 LOT 수량 11건 DB 정정 (BOX×480+낱개) |
