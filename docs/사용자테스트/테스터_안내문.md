# 사용자 테스트 안내문 — 손대시(수기 작업일보 AI 판독 · LOT 추적 대시보드)

> **언제:** 2026-11-08(일) 10:00 ~ 13:00 사이 편한 때 혼자 진행(약 15~20분)

> **문의:** 진행자(팀장)에게 메시지

## 1. 테스트 목적

손글씨 작업일보를 AI 가 읽어 DB 에 넣고, 제품 LOT 을 원소재까지 추적하는 서비스가 **현장에서 쓸 만한지** 확인합니다. 정답을 맞히는 시험이 아니라 **어디서 막히는지**를 알려 주시는 것이 목적입니다. 막히면 그 과제는 건너뛰고 폼에 "못함"과 막힌 곳을 적어 주시면 됩니다.

## 2. 동의 (폼 첫 문항에서 체크)

- 폼에 남기는 것: 역할, 과제 완료 여부·걸린 시간, 설문, 자유 의견.
- **남기지 않는 것:** 이름, 이메일, 연락처, 부서명. (폼은 이메일을 수집하지 않습니다)
- 사용 목적: 서비스 개선과 과제 발표의 "사용자 테스트 결과" 요약. 이름 없이 집계해서만 씁니다.
- **화면 녹화는 선택입니다.** 하실 수 있으면 `Win + G`(Xbox Game Bar)로 화면만 녹화(마이크 끔)하고 진행자에게 따로 보내 주세요. 녹화 파일은 발표(2026-11-12) 후 30일 안에 삭제합니다.
- 언제든 중단할 수 있고 불이익이 없습니다.

## 4. 과제 (순서대로, 대략 걸린 시간을 기억해 폼에 적어 주세요)

### 과제 1. 9월 IV 생산량 보기 (목표 2분)

1. 주소를 열고 위쪽 모델 단추에서 **IV** 를 누릅니다.
2. 기간을 2026-09-01 ~ 2026-09-30 으로 맞춥니다.
3. 그래프에서 날짜별 생산 수량과 불량을 찾으면 성공입니다.

### 과제 2. 대화창 질문 하나로 LOT 흐름 따라가기 (목표 3분)

1. 오른쪽 **대화창**에 `9/10 사출 LOT 흐름` 을 입력합니다.
2. 위쪽에 '대화 질문 기준' 띠가 생기고, 공정 흐름 그림이 **사출 → 스티칭 → 권선 → 압입 → 최종검사**로 이어지는지 봅니다.
3. 공정 단추(사출·스티칭·권선·압입·최종검사)를 눌러도 그 LOT 들만 보이는지 확인합니다. 끝나면 띠의 **해제** 단추를 누릅니다.

### 과제 3. AI 에게 자유롭게 물어보기 (목표 3분)

예시 중 2개 이상, 또는 궁금한 것을 물어보세요. 답에 "AI(Claude) 생성" 표시가 있는지, 화면 숫자와 맞는지 봅니다.
- `9월 IV 권선 불량 상위 3개는?`
- `IV ZIC LOT 추적해줘`
- `9월 최종검사 불량률이 가장 높은 모델은?`

### 과제 5. (로그인 계정 있는 분만) 작업일보 사진을 AI 로 읽히기 (목표 4분)

1. 대시보드 오른쪽 위 **입력 🔒** 또는 [관리 화면](https://m1-3-imeb3-dashboard.onrender.com/manage.html?tab=mixed)을 열고 로그인합니다.
2. **③ 사출·조립 작업일보** 탭에서 진행자가 보내 준 PDF 를 고르고 **OCR 시작**을 누릅니다(쪽당 약 15초).
3. 결과 표와 원본을 비교해 **틀린 칸이 몇 개인지** 세어 봅니다. 노란 칸은 AI 가 확신하지 못한 칸입니다.
4. **DB에 저장은 누르지 마세요.** (실제 기록과 겹칩니다)
