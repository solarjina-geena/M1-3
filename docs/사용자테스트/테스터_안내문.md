# 사용자 테스트 안내문 — 수기 작업일보 AI 판독 · LOT 추적 서비스

> 소요 시간 약 15분 · 테스트 기간 2026-11-05 ~ 11-08 · 문의는 진행자(팀장)에게
> 이 문서는 테스터에게 그대로 보내는 안내문입니다. 아래 "진행자 체크리스트"는 팀 내부용입니다.

## 1. 테스트 목적

손글씨 작업일보를 AI 가 읽어 DB 에 넣고, 제품 LOT 을 원소재까지 거꾸로 추적하는 서비스가 **현장에서 쓸 만한지** 확인합니다. 정답을 맞히는 시험이 아니라 **어디서 막히는지**를 알려 주시는 것이 목적입니다. 막히면 막힌다고 말씀해 주시는 것이 가장 큰 도움입니다.

## 2. 시작 전 확인 (동의)

- 기록하는 것: 역할(품질/생산/전산 입력/기타), 과제 완료 여부와 걸린 시간, 설문 5문항, 자유 의견, **화면 녹화**(얼굴·음성은 녹화하지 않습니다).
- 기록하지 않는 것: 이름, 연락처, 소속 부서명.
- 사용 목적: 서비스 개선과 과제 발표의 "사용자 테스트 결과" 요약. 이름 없이 집계해서만 공개합니다.
- 녹화 파일은 진행자 PC 에만 두고 발표(2026-11-12) 후 30일 안에 삭제합니다.
- 언제든 중단할 수 있고 불이익이 없습니다.

위 내용에 동의하시면 시작합니다. (자세한 기준: [개인정보 처리 방침](../개인정보_처리방침.md))

## 3. 준비

| 항목 | 내용 |
|---|---|
| 브라우저 | Chrome 또는 Edge (PC 권장) |
| 주소 | https://m1-3-imeb3-dashboard.onrender.com |
| 첫 접속 | 무료 서버라 첫 화면이 뜨기까지 30~60초 걸릴 수 있습니다. 흰 화면이면 잠시 기다린 뒤 새로고침하세요 |
| 로그인 | 과제 1~3 은 로그인 없이 됩니다. 과제 4 만 진행자가 알려 주는 테스트 계정으로 로그인합니다 |
| 화면 속 데이터 | 2026년 8·9월 실적입니다. 사람 이름은 가려서 표시됩니다(예: 박*식) |

## 4. 과제 (순서대로, 각 과제의 걸린 시간을 진행자가 잽니다)

### 과제 1. 9월 IV 모델의 생산량 추이 보기 (목표 2분)

1. 주소를 열면 **전체흐름 대시보드**가 뜹니다. 위쪽 모델 버튼에서 **IV** 를 누릅니다.
2. 기간을 **직접 선택**으로 바꾸고 2026-09-01 ~ 2026-09-30 으로 맞춥니다.
3. 그래프 상자 안의 날짜와 수량이 보이면 성공입니다.
4. 같은 내용을 표로 보려면 화면의 **표·그래프 보기** 링크(또는 주소 뒤에 `/tables.html`)를 열어 "일자별 생산량" 그래프를 확인합니다.

> 묻고 싶은 것: 어느 숫자가 생산량이고 어느 숫자가 불량인지 바로 알 수 있었나요?

### 과제 2. 제품 LOT 하나를 원소재까지 거꾸로 추적하기 (목표 3분)

1. 전체흐름 대시보드에서 모델 **IV**, 날짜 **2026-09-10** 을 고릅니다. (이날 압입(CA) LOT 번호는 `260910D1` 입니다.)
2. 그래프에 **압입(CA) → 권선(BA) → 스티칭 → 사출 → 수지 LOT** 이 한 줄로 이어지고, 오른쪽에 최종검사 상자가 붙어 있으면 성공입니다.
3. 표 화면의 **사슬 점검표(CA 제품 LOT)** 에서 같은 LOT 의 행을 찾아 "완전" 표시를 확인합니다.
4. 다른 예: IV `260903D1` (2026-09-03).

> 묻고 싶은 것: 화살표 방향과 "CANDIDATE(후보)" 표시의 뜻이 이해됐나요? 어느 단계에서 멈칫했나요?

### 과제 3. AI 창에 질문하기 (목표 3분)

1. 대시보드 오른쪽 **AI 창**에 아래 질문을 하나씩 입력합니다. (예시 버튼을 눌러도 됩니다.)
   - `9월 IV 권선 불량 상위 3개는?`
   - `260903D1 LOT 의 상위 LOT 은?`
   - `IV ZIC LOT 추적해줘`
2. 답이 나오면 **"AI(Claude) 생성"** 표시가 있는지, 숫자가 과제 1·2 에서 본 값과 맞는지 봅니다.

> 묻고 싶은 것: 답이 믿을 만했나요? 어떤 질문을 더 하고 싶었나요?

### 과제 4. 작업일보 사진을 AI 로 읽히기 (목표 4분, 로그인 필요)

1. 표 화면 맨 아래 **관리자 입력 🔒** 에서 진행자가 알려 준 테스트 계정으로 로그인합니다.
2. **보조 입력** 을 열고 "작업일보 사진 → Claude 가 읽기" 에서 진행자가 준 사진(또는 PDF) 한 장을 고르고 **OCR 시작**을 누릅니다. 20초쯤 걸립니다.
3. 표가 뜨면 **"AI 판독값 — 사람 확인 전"** 표시를 확인하고, 사진과 비교해 **틀린 칸이 몇 개인지** 세어 봅니다.
4. 저장은 누르지 않아도 됩니다. (저장하면 "후보" 상태로 들어가고 테스트 뒤 무효 처리합니다.)

> 묻고 싶은 것: 틀린 칸을 찾아 고치기 편했나요? 어떤 칸이 자주 틀렸나요?

### 과제 5. (선택) 팀 OCR 검토·적재 앱 한 번 보기 (목표 2분)

관리자 입력 탭 위쪽의 **팀 검토·적재 앱** 화면을 둘러보고, 과제 4 의 보조 입력과 비교해 어느 쪽이 편한지 말해 주세요.
