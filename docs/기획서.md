## 1. 문제 정의

iMEB3 제품(IV/OV/HSV 3종)은 사출 → 스티칭 → 권선(BA) → 압입(CA) → 최종검사 다섯 공정을 거친다. 각 공정은 **종이 작업일보**에 손글씨로 생산수량·불량수량·작업시간·투입 자재 LOT 날짜를 적는다.

종이로만 남는 기록 때문에 생기는 문제:

| 문제 | 현장에서 벌어지는 일 |
|---|---|
| LOT 추적 불가 | 고객 불량이 접수되면 그 제품이 어느 날 어느 수지·보빈·리드핀으로 만들어졌는지 일보 더미를 뒤져야 한다. 하루 이상 걸린다. |
| 원인 분석 불가 | 불량 유형(용접·비전·깊이·저항)이 어느 날, 어느 자재 LOT, 어느 설비 조건에서 늘었는지 집계할 수 없다. |
| 전산 입력 지연·오류 | 월말에 사람이 일보를 엑셀로 옮기며 시간이 들고 입력 오류가 생긴다. |

## 2. 타겟 사용자

| 사용자 | 하고 싶은 일 | 서비스에서 쓰는 화면 |
|---|---|---|
| 품질 담당자 (1차) | 불량 LOT 하나를 넣고 원소재까지 역추적, 같은 자재를 쓴 다른 LOT 찾기 | LOT 추적, AI 대화창 |
| 생산 담당자 | 일자별 생산량·불량 추이, 공정별 불량 유형 | 공정 그래프, 개요 |
| 전산 입력 담당자 | 스캔한 일보를 올리고 판독값을 확인·수정한 뒤 저장 | 관리자 입력(OCR 검토·적재 앱) |

## 3. 서비스 개요

**"스캔 → AI 판독 → 사람 검토 → DB 적재 → 추적·그래프·대화"** 한 흐름.

1. 작업일보 PDF·사진을 올린다.
2. Claude(멀티모달)가 칸 단위로 숫자와 자재 LOT 날짜를 읽는다. 읽은 값은 "AI 판독값, 사람 확인 전"으로 표시한다.
3. 담당자가 화면에서 확인·수정하고 승인하면 Supabase `mqi` 스키마(50개 테이블)에 적재된다.
4. 적재와 동시에 LOT 사슬(수지 → 사출 → 스티칭 → 권선 → 압입 → 최종검사)이 날짜 규칙으로 후보 연결(CANDIDATE)되고, 사람이 확인하면 확정(CONFIRMED)된다.
5. 대시보드에서 공정 그래프·사슬 점검표·LOT 추적을 보고, AI 대화창에 자연어로 묻는다. 대화창의 숫자는 전부 DB 조회 도구 결과만 쓴다.

## 4. AI 활용 방식

| 기술 요소 | 적용 | 근거 |
|---|---|---|
| 멀티모달 AI | 손글씨 일보 이미지·PDF → 구조화된 숫자 | Claude API 비전. 공정별 필수 항목 체크리스트 프롬프트, 불확실 칸은 "검토 필요" 표시 |
| 자동화 워크플로우 | 업로드 → 판독 → 검토 → 적재 → 사슬 연결 → 뷰 갱신 | FastAPI 백엔드 + Supabase RPC. 사람 승인 단계를 반드시 거침 |
| AI Agent | 대화창 질문 → 도구 선택 → DB 조회 → 답변 | Claude tool use. 도구 5종(생산 요약·공정 시계열·불량 유형·LOT 이력·사슬 끊김). 도구 호출 내역을 화면에 함께 표시 |

AI가 만든 값에는 모두 "AI 생성/AI 판독값" 표시를 붙이고, DB 저장은 사람 승인 후에만 한다.

## 5. 기대 효과와 성공 기준

| 지표 | 현재(종이) | 목표 | 측정 방법 |
|---|---|---|---|
| LOT 한 건 역추적 시간 | 반나절~하루 | 1분 이내 | 사용자 테스트 시나리오 측정 |
| 일보 1장 전산 입력 시간 | 수 분(수기 입력) | 판독 + 확인 1분 내외 | 사용자 테스트 |
| OCR 판독 정답률(생산수량·불량수량) | — | 측정·공개 | 정답지 엑셀 대조, 확인 후 **62.3%**(2026-10-31) |
| 완전 LOT 사슬 비율 | 0 | 적재 범위 안에서 최대 | CA 제품 LOT 기준 49/74 (8·9월) |

판독 정답률은 현재 수준을 솔직히 제시하고, 오류 유형(값 누락 47%, 숫자 오독 43%)을 바탕으로 프롬프트·검토 UI 개선 방향을 보여 주는 것이 발표 핵심이다.

## 6. 범위

**포함:** iMEB3 3모델, 2026년 8·9월 작업일보(사출·스티칭·조립·최종검사), LOT 추적, 공정 그래프, AI 대화창, OCR 입력·검토, 외부 접근 배포.
**제외(확장 후보):** 사출조건표·설비 수리 이력 연동, RAG 기반 원인 분석, 타 제품군, 모바일 전용 UI.
