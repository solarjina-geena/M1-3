# 기능 요구 명세서 — 수기 작업일보 AI 판독 · LOT 추적 서비스

| 항목 | 내용 |
|---|---|
| 문서 상태 | 초안 v0.1 (2026-10-31) |
| 구현 위치 | 백엔드 `backend/app`, 화면 `frontend/`, 도구 `tools/`, DB Supabase `mqi` 스키마 |

## 1. 기능 요구사항 (FR)

### FR-1 작업일보 판독·입력

| ID | 요구사항 | 상태 | 구현 |
|---|---|:---:|---|
| FR-1.1 | 작업일보 PDF·이미지를 올리면 공정 종류(사출·스티칭·조립·최종검사)를 구분해 칸 단위로 값을 읽는다 | ✅ | 팀 OCR 검토·적재 앱(Streamlit, 이*규) + M1-3 보조 입력 `/api/journal/preview-image` |
| FR-1.2 | 읽은 값은 "AI 판독값, 사람 확인 전"으로 표시하고 담당자가 수정할 수 있다 | ✅ | `manage.html` 미리보기, 팀 앱 셀 단위 검토 |
| FR-1.3 | 승인된 값만 DB에 저장한다. 저장은 로그인한 담당자만 할 수 있다 | ✅ | Supabase Auth 이메일 로그인 + 허용 목록, RPC `m13_journal_save` |
| FR-1.4 | 엑셀·CSV 양식 업로드로 여러 일보를 한 번에 적재한다 | ✅ | `/api/journal/preview-file`, `/api/journal/batch`, 양식 내려받기 |
| FR-1.5 | 같은 일보를 두 번 올려도 중복 행이 생기지 않는다 | ✅ | 결정적 ID(uuid5) + ON CONFLICT DO NOTHING |
| FR-1.6 | 삭제 대신 기록 상태(ACTIVE/VOID)로 무효화한다 | ✅ | `record_state`, 감사 컬럼 |

### FR-2 LOT 사슬 연결

| ID | 요구사항 | 상태 | 구현 |
|---|---|:---:|---|
| FR-2.1 | 적재된 일보의 자재 LOT 날짜로 상위 공정 LOT을 자동 연결한다(후보 CANDIDATE) | ✅ | 변환기·RPC의 날짜 규칙: 15일 범위, 보빈 날짜 동일 일보 모두, 조견표 마킹코드(Z+월+일) |
| FR-2.2 | 사람이 후보 연결을 확정(CONFIRMED)하거나 무효화할 수 있다 | ✅ | `/api/links/confirm`, RPC `m13_link_confirm` |
| FR-2.3 | CA 제품 LOT마다 사슬이 어디까지 이어졌는지와 끊긴 첫 자리를 보여 준다 | ✅ | 뷰 `m13_lot_chain_gaps`, 사슬 점검표 |
| FR-2.4 | 최종검사 차수(1차/2차), 재검, 리워크를 LOT에 연결한다 | ✅ | `inspection_run_link`, `rework_record` |

## 3. AI 활용 명세

| 항목 | 내용 |
|---|---|
| 모델 | Claude(Anthropic API 직접 호출). 판독·대화창 모두 동일 계정 키 |
| 판독 프롬프트 | 공정별 필수 항목 체크리스트(생산수량·작업시간·불량 유형·자재 LOT 날짜), 주/야 구분, 읽지 못한 칸은 비워 두고 "검토 필요" 표시. 작업자 이름은 읽지 않는다 |
| 대화 에이전트 | 시스템 프롬프트에 "숫자는 도구 결과만" 규칙. 도구 5종의 입력(model, process, 기간, lot_code)·출력은 PostgREST 뷰 결과 |
| 품질 관리 | 정답지 대조로 정답률 측정(확인 후 62.3%), 오류 유형 집계로 프롬프트 개선 우선순위 결정(값 누락 → 체크리스트 강화, 행 밀림 → 항목명·수량 쌍 검증) |
| 사람 개입 | 판독값 저장 전 확인, LOT 연결 CANDIDATE → CONFIRMED |

## 4. 데이터 요구사항

| 데이터 | 출처 | 보관 |
|---|---|---|
| 작업일보 원본(PDF·사진) | 공장 스캔 | 로컬·팀 공유 폴더만. 저장소 미공개 |
| 판독값·적재 행 | AI 판독 → 검토 | Supabase `mqi` (공정 실행, 결과, 품질 소견, 자재 사용, LOT, 연결) |
| 정답지 엑셀 | 회사 전산(박*경 정리) | 로컬. 집계 수치만 보고서에 공개 |
| 작업자 | 가린 표시명 | `mqi.worker` |

## 5. 검수 기준 (사용자 테스트와 연결)

| 시나리오 | 통과 기준 |
|---|---|
| LOT 역추적 | LOT 코드 입력 후 1분 안에 수지·사출·스티칭·권선 LOT과 최종검사 결과가 보인다 |
| 불량 추이 | 모델·기간을 바꿔 그래프가 갱신되고 값이 표와 같다 |
| 대화창 | "9월 OV 용접불량 합계" 같은 질문에 도구 호출과 숫자가 나온다 |
| OCR 입력 | 일보 사진 1장을 올려 판독값을 확인·수정·저장하면 LOT 추적 탭에 나타난다 |
| 권한 | 로그인 없이 저장 시도는 거부된다 |
